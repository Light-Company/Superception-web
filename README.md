# Superception web

Production homepage for https://superception.ai.

- `index.html` and `assets/`: production page.
- `draft/`: local archive of older pages; excluded from Git and deployment.
- `npm run check`: script syntax, local links, and build boundaries.
- `npm run build`: outputs only the homepage and its assets in `dist/`.
- Pushes to `main` deploy through GitHub Actions to GitHub Pages.

The hero is a silent 77.25-second edit, excluding Light Company lab shots. Camera shots with embedded letterboxing are cropped to fill. Figure footage remains excluded.
