# Homepage logos

- Meta: https://commons.wikimedia.org/wiki/File:Meta_Platforms_Inc._logo.svg — original source attributed to Meta's Brand Resource Center; monochrome treatment applied in CSS.
- MIT: exact logo path from the public footer of https://www.mit.edu/ ; white fill for the dark background. Guide: https://brand.mit.edu/logos-marks/mit-logo
- Harvard: exact `.svgicon-logo-light` SVG from https://www.harvard.edu/wp-content/themes/core/assets/css/dist/theme/master.min.css ; grayscale treatment applied in CSS, preserving shield detail.
- Apple: exact official path from https://www.apple.com/ac/globalnav/2.0/en_US/images/ac-globalnav/globalnav/apple/image_large.svg ; viewport trimmed to remove navigation padding.

These marks identify the team backgrounds supplied by the user. The page does not label these organizations as customers, partners, or sponsors.
